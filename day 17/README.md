Project: Progressive Overload Tracker (CLI)

A simple command-line workout tracker built without functions or advanced Python features.

The goal was to reinforce structured thinking, data handling, and logical flow.

Data Structure

Each workout is stored as:

["exercise_name", sets, reps]


All workouts are stored inside a main list.

Features

View workouts

Add workout

Update workout (sets or reps)

Delete workout

Check progress

Exit

Progress Logic

For each workout:

Total reps = sets × reps

Training intensity is categorized as:

> 40 total reps → Very strong

25–40 total reps → Strong

< 25 total reps → Can improve
