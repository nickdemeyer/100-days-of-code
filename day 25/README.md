__Python Object-Oriented Programming (OOP) Fundamentals__
This repository contains my initial explorations into Python Classes and Objects. After mastering functions, I've taken the next step to understand how to group data and behavior together using Object-Oriented Programming.

__Concepts Learned Today__
Throughout these exercises, I've focused on the core building blocks of OOP:
- Classes: Creating "blueprints" for objects (e.g., Car, Person).
- Objects (Instances): Creating unique "packages" of data based on a class.
- The __init__ Method: Using a constructor to initialize multiple attributes at once.
- Attributes: Storing state within an object using self.
- Methods: Defining functions inside a class that are tied to the object's data.
- User Input Integration: Learning how to bridge the gap between user interaction and object creation.

__Exercises Completed__
1. Car Blueprint
A basic class to store vehicle information and display it in a formatted string.
- Skills: Attribute assignment and basic method printing.
2. Person & Age Calculator
A class that takes a name and birth year, then calculates the person's age.
- Skills: Using self for calculations and implementing return values in methods.
