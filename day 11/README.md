__Project 1 – Grocery List Manager__

__Description__
This is a simple command-line grocery list manager built in Python.
It allows the user to keep track of items they want to buy.

__Features__

- View all items in the grocery list

- Add new items

- Remove items by selecting a number

- Prevents errors when invalid numbers are entered

- Runs in a loop until the user chooses to exit

__Concepts Practiced__

- Lists and list indexing

- Adding and removing items from a list

- Using loops to display data

- Handling user input

- Basic input validation

- Converting user input from text to numbers


__🎬 Project 2 – Movie Watchlist Manager__

__Description__
This is a small Python program where users can manage a list of movies they want to watch.

__Features__

- Display all movies in the watchlist

- Add new movies

- Remove a movie by choosing its number

- Handles incorrect input safely

- Runs continuously until the user exits

__Concepts Practiced__

- Working with lists

- Looping through lists with numbered output

- Removing items using their position in the list

- Input validation and error prevention

- Converting user input into usable program data
