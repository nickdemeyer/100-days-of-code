# Contact List 

## 📌 Project Description
This is a simple command-line contact list application written in Python.  
The goal of this project was to practice working with lists, user input, and basic program logic — without relying on AI autocomplete or copy-pasting solutions.

## 🎯 Features
The user can:
- View all contacts
- Add a new contact
- Delete a contact by selecting its number
- Exit the program

## 🧠 What I Learned
This project helped me better understand:
- How Python lists work internally
- The difference between user-friendly numbering and zero-based indexing
- How to safely remove items from a list
- Why input validation is important
- The mental process behind translating logic into code

Turning off AI autocomplete made this project significantly more challenging, but also much more educational.
