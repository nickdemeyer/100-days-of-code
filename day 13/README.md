# Day 13 — Python List Practice Projects

## 📌 Overview
This day was focused entirely on practicing and deepening my understanding of Python lists.

I worked through multiple small projects of increasing difficulty, starting with simple list manipulation and ending with nested lists (lists inside lists).

The goal was not to learn new concepts, but to **strengthen problem-solving and data structure understanding**.

---

## 🏋️ Project 1: Gym Exercise List

### Description
A simple command-line program where the user can:
- View exercises
- Add new exercises
- Delete exercises by number
- Exit the program

### Concepts Used
- Lists
- Indexing
- User input
- Loops
- Basic validation

---

## 🐱 Project 2: Pokémon List

### Description
Another list-based program with the same structure as the gym exercise list.
This project reinforced:
- Repetition without copying blindly
- Thinking in numbers vs list indexes
- Rebuilding logic without assistance

### Concepts Used
- Lists
- for loops
- enumerate
- Removing items by index

---

## 🏋️‍♂️ Project 3: Workout Tracker (Nested Lists)

### Description
A more advanced command-line application where each workout contains:
- Workout name
- Number of sets

Each workout is stored as a list inside a main list.

The user can:
- View all workouts
- Add a workout (name + sets)
- Update the number of sets
- Delete a workout
- Exit the program

### Key Learning Challenge
The biggest difficulty was understanding how to:
- Access data inside a nested list
- Update a single value without recreating the list
- Use indexing correctly when modifying existing data

Example concept:
`workouts[index][1]`

This project took significantly longer than the previous ones, but led to a much deeper understanding of how data structures work in practice.

---

## 🧠 Key Takeaways
- Lists become powerful when you truly understand indexing
- Nested lists require a clear mental model
- Struggling is part of building real problem-solving skills
- Rebuilding similar projects helps concepts stick
